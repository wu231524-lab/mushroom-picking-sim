## 首要目标

一次启动、一次触发，自主完成多颗蘑菇的目标选择、采摘、放置及下一颗接续，全部处理结束后返回 HOME。

开发顺序：

1. 保留当前成功基线，解除固定目标和固定抓取姿态的绑定。
2. 根据本次目标生成预抓取、接近、提升和搬运路径，支持 follower 切换实体；先采摘第二个位置的单颗。
3. 建立批次循环，每颗放置后恢复全局观察，清理单颗临时状态，为下一颗建立新锁和观测。
4. 记录未采摘、处理中、已放置和跳过目标；区分采摘区与放置区，避免重复采摘。
5. 连续两颗 → 连续现有四颗 → 重复整批运行并修复首个实际失败。

复用现有 YOLO、严格同步、球面拟合和 XY 闭环，优先解决跨目标接管和尺寸/高度适应。完整碰撞规划、高保真物理、复杂密集场景和全面测试框架后置。

保留目标/观测有效、关节可解且在限位内、单条在途运动、Action 结果及超时、吸附/脱附一致性等必要执行约束，由主控制器负责。外部重复调用现有单颗 `run_once` 不能代替批次状态机。
